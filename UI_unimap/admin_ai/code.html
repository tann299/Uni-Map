Khởi chạy Huấn luyện Mô hình (UC-10)

Quy trình sẽ thực thi các tác vụ tính toán sau trên cụm máy chủ xử lý:

  1. Trích xuất dữ liệu 2021–2025 từ Data Warehouse Tuyển sinh.
  2. Thực hiện Temporal Split (Train: 2021–2024, Test: 2025) để ngăn Data Leakage.
  3. Huấn luyện Random Forest 350 cây với GridSearchCV trên 5 tham số.
  4. Đánh giá chéo và sinh báo cáo so sánh chỉ số Accuracy, F1, Precision, Recall.
Thời gian ước tính hoàn thành: ~ 3 phút 45 giây
