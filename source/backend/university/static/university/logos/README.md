# Logo trường đại học

Đặt logo thật vào thư mục này, tên file **trùng mã trường** (viết hoa), ví dụ:

- `BKA.png` → Đại học Bách khoa Hà Nội
- `NEU.png` → Kinh tế Quốc dân
- `HUMG.png` → Mỏ - Địa chất

Hỗ trợ đuôi: `.png`, `.jpg`, `.jpeg`, `.svg`, `.webp`.

Web tự ưu tiên hiển thị ảnh khi có file; không có file thì tự dùng monogram chữ viết tắt làm fallback. Không cần sửa code.

Danh sách mã trường xem ở bảng `truong` (cột `ma_truong`).
